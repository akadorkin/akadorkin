# Alexander Kadorkin

Technical product manager who builds. 10+ years in product: seller platforms and catalogs for marketplaces (Megamarket, Samokat, Magnit), a cross-platform games SDK (VK), digital merchandising (X5). Before that, tariffs and billing at Beeline.

Since 2025 I also run my own subscription service on my own, with AI agents handling on-call, support and routine operations: 20+ servers in 8 countries, monitoring, payments. The tooling I wrote for it is below.

## Tools

- [mia-assist](https://github.com/akadorkin/mia-assist): MCP server + CLI to run a server fleet over SSH/Tailscale. Status, audit, drift snapshots, two-step plan → apply with a journal.
- [mcp-remnawave](https://github.com/akadorkin/mcp-remnawave): MCP server for the Remnawave panel (fork, v3 rework). Safe edits with diff + confirm, backups, journal.
- [remnanode-install-script](https://github.com/akadorkin/remnanode-install-script): one-command bootstrap and hardening of a VPS node.
- [vps-network-tuning-script](https://github.com/akadorkin/vps-network-tuning-script): network tuning profiles with verification and rollback.
